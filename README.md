# J. Store
## https://jaystores.vercel.app

An online storefront for women's lawn and embroidered clothing, built as a set of
static HTML pages backed by Supabase. The catalogue, product images and orders all
come from Supabase, while the bag is kept in the browser's local storage, so the
whole shop runs without a server of its own: browse the trending products on the
home page, open one for detail, add it to your bag, and check out with an email and
delivery address. There are also pages for corporate and festive gifting, sign-in,
and order tracking.
